# Victoria Mix Innova – Sitio Web
Sitio estático para la tienda de joyas de plata ubicada en Mall Plaza Copiapó (frente a Lápiz López).

## Estructura
- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/img/` (coloca tus imágenes aquí)

## Publicación en GitHub Pages
1. Crea repo `victoria-mix-innova` y sube estos archivos.
2. Settings → Pages → Deploy from a branch → main / (root).
3. Abre la URL generada por GitHub Pages.
